# Project Sidereal
## Brief
'Sidereal' is an agentic platform with a web front-end that runs on this vm that periodically scans the internet for certain topics to keep me up to date.

## Specifics
* Searches multiple sources from the internet for focus areas (SEE 'Focus Areas' heading below)
* Uses a local model (ollama hosted at http://192.168.221.1:11434) 
* Can use pi.dev harness if needed (its installed)
* Runs as a service, every 4 hours)
* Has a webinterface (React?)
* Has a 'Daily' tab
** Groups all runs under days.
** Each day will be selectable on the left pane and display 'Sunday - 14.07.2026' etc
** When selected it groups all of the most important info within this day-specific sub-gazette
* Has a main page called 'gazette'
* In all views, the data is grouped as 'TOP, Relevant, On the side' - grouping all info into those specific sections, where TOP is the most relevant and important I should know / read about.
